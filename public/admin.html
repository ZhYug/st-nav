数据管理

安全导入、导出和恢复导航数据。建议修改前先做一次 JSON 备份。

CSV 导入

先预览，再处理重复短码，不会直接写入数据库。

支持 code,url,title,description,category,enabled。重复短码可选择跳过、覆盖或自动生成新短码。

JSON 备份

备份短链接、导航、设置及点击统计。

备份文件可用于完整迁移或灾备。下载文件保存在你的设备上。

JSON 恢复

支持合并恢复或完全覆盖恢复。

覆盖恢复会清空当前短链接、导航、统计和设置，再写入备份内容；操作前会再次确认。

恢复策略说明

建议日常使用“合并恢复”，换站或灾难恢复使用“完全覆盖”。
合并恢复

短链接按短码更新或新增；导航尽量按关联短链接恢复；设置覆盖同名项；不会删除当前未出现在备份中的数据。

完全覆盖

先清空现有业务数据，再恢复备份中的全部数据。适合将当前站点恢复到备份时的状态。
